# Enterprise Attack Detection & Response Lab: Demonstration & Portfolio Guide

## 1. Overview

This step-by-step demonstration guide enables evaluators, security hiring managers, and SOC analysts to reproduce the full end-to-end security operations lifecycle:

```
[ Attack Simulation ] ──► [ Telemetry Normalization ] ──► [ Sigma Detection ] ──► [ Security Alert ]
                                                                                         │
[ Executive Report ] ◄─── [ SOAR Containment ] ◄─── [ Automated Investigation ] ◄────────┘
```

---

## 2. End-to-End Demonstration Walkthrough

### Step 1: Environment Status & Isolation Validation
Verify the lab topology, non-overlapping RFC 1918 subnets, and infrastructure nodes:

```bash
# Display topology, active subnets, and services
python3 cli.py status

# Validate network segmentation and firewall isolation policies
python3 cli.py validate

# Run deep health checks across all 7 lab subsystems
python3 cli.py health
```

---

### Step 2: Execute Realistic Attack Simulation
Simulate an adversary executing OS Credential Dumping against the Domain Controller (MITRE ATT&CK `T1003`):

```bash
python3 cli.py simulate -s SCN-CRED-004
```

*Expected Result:*
- Adversary executes memory dumping against `lsass.exe` on `dc01.corp.enterprise.local`.
- Normalized ECS security events are ingested into the SIEM collector.

---

### Step 3: Detection Rule Triggering & Alert Review
View high-fidelity security alerts generated by the Detection Engine:

```bash
python3 cli.py alerts
```

*Expected Result:*
- Detection rule `DET-CRED-004` triggers a **HIGH / CRITICAL** severity alert with MITRE ATT&CK mapping `T1003.001`.

---

### Step 4: Automated Multi-Source Investigation & Correlation
Trigger the Automated Investigation Engine to correlate multi-source logs, synthesize a chronological timeline, extract IOCs, and reconstruct the root cause:

```bash
python3 cli.py investigate -s SCN-CRED-004
```

*Expected Result:*
- Automatically generates an Incident (`INC-XXXX`).
- Correlates Windows EventLog, Sysmon, and network flow telemetry.
- Synthesizes root cause analysis and identifies compromised service accounts.

---

### Step 5: Execute Automated Incident Response Playbook (SOAR)
Execute the Credential Compromise Response Playbook to contain the threat and record an immutable audit log:

```bash
python3 cli.py respond -p credential
```

*Expected Result:*
- SOAR engine isolates affected identities, revokes active Kerberos sessions, and blocks malicious IPs.
- Status updates: `Containment: CONTAINED`, `Remediation: REMEDIATED`, `Recovery: VERIFIED`.
- Audit entry logged with reversible rollback state.

---

### Step 6: Generate Structured Multi-Format Incident Report
Export structured incident reports covering all 12 standard sections:

```bash
# Output Markdown report to terminal
python3 cli.py report --format md

# Export self-contained HTML report
python3 cli.py report --format html --output incident_report.html

# Export structured JSON report
python3 cli.py report --format json --output incident_report.json
```

---

### Step 7: Launch Interactive Web SOC Dashboard
Start the Uvicorn server and explore the web interface:

```bash
python3 cli.py serve --port 8088
```

Open your browser to: **`http://localhost:8088/dashboard`**

**Key Web Dashboard Capabilities:**
1. **Live Metrics Banner:** Real-time MTTD (0.05s), MTTR (1.50s), Detection Rate (100%), and System Health (100%).
2. **MITRE Heat Grid:** Interactive visual activity counter across all 10 tactics.
3. **Alerts Feed:** Search, filter, and click **"🚀 Investigate"** to launch the 7-step guided workflow.
4. **Investigation UX Flow:** Step-by-step interactive workflow:
   `Alert -> Incident -> Timeline -> Evidence -> MITRE -> Response -> Resolution`.
5. **MITRE Coverage Catalog:** Browse all 30 detection rules mapped to ATT&CK techniques.
6. **SOAR Audit Log:** Review automated containment actions.
7. **Observability Tab:** Live diagnostic cards for all 7 lab subsystems.
